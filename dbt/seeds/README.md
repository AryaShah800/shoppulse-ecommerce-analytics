# Seeds: a 5,000-order sample of Olist

Generated by `scripts/sample_olist_seed.py` (fixed seed 42, sorted order ids, all rows of the chosen orders, review comment text dropped). Rerun it on the Kaggle files to reproduce byte-identical CSVs.

**Source and licence:** Olist Brazilian E-Commerce Public Dataset by Olist, https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce, licensed CC BY-NC-SA 4.0. This sample is a derivative shared under the same licence, for non-commercial use, with attribution to Olist.

This is a small random sample (about 5% of orders), so it is for testing and demonstrating the dbt models. Do not read business findings off it: customers almost never repeat in a 5% sample, and the headline results in the main README come from the full data in BigQuery.
